The same application as an **installable app** for your phone. It ships everything and works offline.

**Download:** [ritzel-generator.apk](https://github.com/nullforge86/gates-cdx-kettenspanner-ritzel-generator-brompton/releases/download/app/ritzel-generator.apk) – the link stays the same for every new version.

**Install:**

1. Open the link **in your phone's browser** → the file downloads.
2. Open the file (notification or "Downloads" folder).
3. Allow "install from this source" → **Install**.

Install a new version **over the old one**, do not uninstall first.

**Particulars:**

- The ZIP with STL is built on the device and ends up in "Downloads".
- **There is no STEP in the app** (the file needs a CAD program on a computer anyway). The ready-made STEP files are in the "serie" release.

Detailed guide, pitfalls and signing the app: [APK-HERUNTERLADEN.md](../../APK-HERUNTERLADEN.md) (German).
